## Edition Differences

### Java Edition
- PC only (Windows, Mac, Linux)
- Extensive mod support
- LAN multiplayer
- Server hosting options
- $26.95 USD

### Bedrock Edition
- Cross-platform (PC, Console, Mobile)
- Limited add-ons
- Realms Plus
- Optimized performance
- $19.99 - $29.99 USD
